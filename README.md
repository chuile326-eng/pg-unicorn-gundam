# PG Unicorn Gundam

PG 1/60 RX-0 Unicorn Gundam — Final Battle Ver. (Bandai), showcase web kiểu Humaan / Curtin.

- `index.html` — trang chính: hero kiểu Curtin, showreel, thư viện 12 ảnh, khu thả rơi kéo thả được (Matter.js).
- `assets/title-curtin.webp` — ảnh mở đầu: 2 góc Unicorn, chữ UNICORN ở giữa, chấm màu.
- `assets/showreel-v6.mp4` — showreel v6, 46 giây, 960x960, 24fps, đã soi QA từng giây. Chương: mở đầu, lắp ráp (chỉ 1 lần), toàn thân, mắt + Beam Saber, Shield Funnel, vũ khí, NT-D Glow.
- `assets/01-fullbody.webp` … `assets/12-exploded.webp` — 12 ảnh chi tiết đã QA: toàn thân, đầu/ngực, vũ khí/khiên, sau lưng, tay, chân, Beam Saber/Bazooka, phụ kiện, khớp vai/khuỷu, khớp hông/gối, khớp cổ tay/cổ chân/cổ, toàn cảnh tháo rời.

Mở bằng cách mở `index.html` trong trình duyệt, hoặc deploy thư mục này lên bất kỳ static host nào.
